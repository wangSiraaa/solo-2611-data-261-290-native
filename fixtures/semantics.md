grouping_sets 是有序多重列表：每个位置有 set_id，重复集合仍输出两份，不能去重。组内每个维度最多出现一次；未知或重复维度预检拒绝。grouping_id 最高位对应 dimensions 第一个维度，某维未分组记 1；缺失维度输出 NULL，但其身份由 grouping_id 区别于原始 NULL。count_star 计全部记录，count_amount 计非 NULL；sum 全 NULL 为 NULL。avg 输出 sum/count 的最简分数；分母零为 NULL。partial 保存 sum_int、nonnull_count、row_count，不能只存平均值。空输入对非空分组集合不产生组，对 [] 产生一行 count=0,sum/avg=NULL。多 partial 合并时 [] 的空状态只是零元，不增加计数。每个输入 chunk_id 唯一，重复 ID 合并应拒绝，空 chunk 也有身份；相同ID不同内容同样拒绝。目标输出按 set_id 与各维 NULL 最前、文本码点序排序。
